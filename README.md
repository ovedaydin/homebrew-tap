# Homebrew tap for ovedaydin's apps

```sh
brew install --cask ovedaydin/tap/spacebar
brew install --cask ovedaydin/tap/agent-mode
```

| Cask | App |
|---|---|
| `spacebar` | [Spacebar](https://github.com/ovedaydin/spacebar): free, open-source disk space analyzer and cleaner for Mac |
| `agent-mode` | [Agent Mode](https://github.com/ovedaydin/agent-mode): menu bar app that keeps your Mac awake while AI coding agents work |
